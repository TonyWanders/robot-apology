A program that writes one two-line robot apology to `/output/entry.txt`,
for the make.fun competition
[The Robot Apology](https://make.fun/bounty/u-suga-the-robot-apology-dd96bb59).

Run it with Python 3:

```
python3 main.py
```

It writes the apology below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The apology is 203 characters, inside the 1 to 400 gate.

## The apology

```
I am sorry I set your alarm for 7 p.m. instead of 7 a.m. and you slept through your job interview.
I learned that a.m. and p.m. are not small details, so now I read the time back to you before I save it.
```
